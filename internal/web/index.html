TMDB

填写 TMDB API Key 后，本地 NFO 没有演员头像的条目会从 TMDB 补齐演职人员。Key 只保存在本机数据库，页面不会回显；保存空值将清除已存的 Key。
使用自建 TMDB 代理时填代理地址：代理会在服务端注入 Key，此时可不填 Key；演员补齐与高清背景图都会走这个基址。

API 密钥

用于与 Nan（Emby 助手）、MoviePilot 等联动：在对方的 Emby 服务器配置里填影库地址（如 http://192.168.1.5:8097）和下面的密钥。密钥只保存在本机数据库。
开启后，所有 API 请求必须带密钥（api_key 参数或 X-Emby-Token 头），网页端会自动附带。当前浏览器会记住密钥；其他浏览器首次打开时，在地址后加 ?api_key=密钥 访问一次即可记住。开启前请先复制保存好密钥，丢失密钥将无法通过网页管理（需在数据库中清除 api_auth_required 恢复）。
